컬럼 결정 규칙

순서단계동작
1include_columns 가 있으면그 목록만 화이트리스트로 사용
2비어 있으면columns(등록 시점 스냅샷)를 기준선으로 사용
3항상 마지막exclude_columns 제거

기준선을 등록 시점 스냅샷으로 고정하므로, 원천에 컬럼이 새로 생겨도 자동 반영되지 않는다(요구사항).
