← 개요로

include 는 공집합이면 columns(등록 시점 스냅샷)를 기준선으로 쓰고, exclude 는 항상 마지막에 적용됩니다. 원천에만 있는 컬럼은 자동으로 반영되지 않습니다.

오늘 이 파일이 바뀐 이유

exclude(제외) — 해당 컬럼은 ETL 이 적재하지 않는다. 대상 테이블에는 만들어지지 않는다.
include — 비어 있으면 columns 전체가 기준이 된다. 값이 있으면 그 목록만 화이트리스트로 쓴다.
비식별화 — D1 해시(SHA-256) / D2 null 처리 / D3 마스킹.
처리종류 — 증분 적재(append) / 전체 재적재(truncate) / 병합(merge). 병합은 기본키가 반드시 있어야 한다.
활성(Y/N) — N 이면 정규 ETL 이 이 테이블을 건너뛴다. 초기 이관이 끝나야 Y 로 바꾼다.
작업주기 · 요일 · 고정일 — 등록일 이후에, 지정한 요일/날짜에만 실행한다. 그 외에는 건너뛴다(SKIP 로 로그에 남는다).
